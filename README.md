# SentimentAI – Sentiment Analysis Using DistilBERT

## Project Overview
SentimentAI is an AI-powered web application that analyses text and identifies its emotional sentiment as Positive, Negative, or Neutral.

It uses a DistilBERT-based multilingual sentiment analysis model to understand text and provide predictions.

## Features
- AI-powered sentiment analysis
- Positive, Negative, and Neutral classification
- Confidence score for predictions
- Interactive and attractive user interface
- Analysis history
- Sentiment analytics dashboard
- Responsive website design

## Technologies Used
- Python
- Flask
- DistilBERT
- Hugging Face Transformers
- HTML
- CSS
- JavaScript
- Chart.js

## How to Run
1. Install the required Python packages:
   `pip install -r requirements.txt`
2. Activate the virtual environment.
3. Run the application:
   `python app.py`
4. Open `http://127.0.0.1:5000` in your browser.

## Project Objective
The objective is to demonstrate how Natural Language Processing and transformer-based AI models can be used to identify sentiment in written text.
